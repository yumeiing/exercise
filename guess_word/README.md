# 介绍
这是一个简单猜词游戏。  
你每次可以输入5个字母来匹配一个有含义的单词。并根据结果不断调整。
# 自定义
你可以**修改宏**以修改游戏规则。
|宏|含义|默认值|
|--|----|------|
|CI|猜词次数|7|
|CH_LEN|单词长度|5|
|WORD_FILE|单词文件|"word_ans"|
|WORD_NUM|单词总数|4667|
|YES_SYMBOL|结果正确的提示|' '| 
|NO_SYMBOL|结果错误的提示|'X'|
|LIKE_SYMBOL|包含结果的提示|'^'|
## 重要提醒！！！
如果修改单词长度，需同步修改文件内容。  
`words`文件包含大量单词，可作为蓝本进行选取。    

Linux可使用以下命令
```sh
grep -P '^[a-z]{5}$' words > tmp
wc -l < tmp # 获取行数
```
其中`5`可换为你想要的单词长度，并修改`CH_LEN`。  
`WORD_FILE`需换成与`输出文件相同(如例子中的`tmp`)。  
`WORD_NUM`需换成行数(第2条命令)。
